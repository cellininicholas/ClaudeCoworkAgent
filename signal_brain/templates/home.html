What is this?

Signal Brain reads what's happening online in your industry, remembers it, and writes you three social-post drafts in your voice every few hours. It watches sources you choose (Hacker News, subreddits, newsletters, Bluesky), turns the noise into a tidy memory of trends, and notices when something you saw weeks ago suddenly matters again — so you can post about it before the rest of LinkedIn catches on.

You don't run it. It runs itself, on a schedule, in Claude Cowork. You just check in here — or ask Claude /status — and accept or reject the drafts it writes for you.

▸ How it actually works (the technical bit) ▾ Hide details

1. Ingest

Every cycle, the agent pulls the latest items from the sources you've enabled. Each item gets stored with full provenance: where it came from, when it was posted, when we saw it.

2. Extract

Claude reads each item and pulls out atomic claims ("AI agents are replacing point SaaS tools") and concepts ("ai agents", "b2b sales"). Spam and low-signal posts get skipped.

3. Self-heal

This is the interesting part. After every ingest, the agent audits itself:

  • Momentum decay: trends naturally fade — old claims weigh exponentially less than fresh ones (7-day half-life).
  • Stale archival: concepts that haven't shown up in 30 days get archived (not deleted — provenance is preserved).
  • Concept merging: Claude scans the top concepts and merges aliases ("ai agents" + "agentic ai" → one).
  • Contradiction detection: if two claims attached to the same concept disagree, the one from a more reliable source wins; the loser is marked superseded.
  • Reliability learning: when you accept a post draft, the sources that fed it get a small reliability boost. Reject it, and they take a hit. The agent learns which sources actually move the needle for you.

4. Draft

Claude looks at the top trends and your bio and writes three posts: one ride-the-trend, one contrarian angle, and one callback — connecting an older trend that's re-emerging to something current. Drafts stay drafts. You publish them yourself.

5. Audit log

Every self-healing action is recorded — see the Audit tab. You can read exactly what the agent decided, when, and why. No black box.

This page is a passive viewer. The agent runs on its own schedule via Claude Cowork. To trigger a run manually, type /cycle. To check status without opening this page, type /status.
